PROJECT OVERVIEW
════════════════════════════════════════════════════════════════════════════

A production-ready VTK Python visualization framework featuring:

✨ VISUAL ENHANCEMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🎬 Multi-Viewport System
  ├─ 1+3 Layout (Isometric + 3 Orthographic views)
  ├─ Synchronized actor rendering across viewports
  ├─ Independent camera control per viewport
  └─ Responsive grid-based arrangement

  🎨 Advanced Rendering Pipeline
  ├─ 3-Point Professional Lighting (Key, Fill, Back)
  ├─ Material System (Glossy, Metallic, Matte)
  ├─ Specular highlights and edge visibility
  ├─ Gradient background with dark theme
  └─ Real-time 60 FPS rendering

  📊 Rich Information Overlays
  ├─ Viewport titles with color coding
  ├─ Object bounds and dimensions display
  ├─ Coordinate system axes (RGB: XYZ)
  ├─ View plane identification
  └─ Professional typography

  🎯 Interactive Controls
  ├─ Mouse-based 3D rotation (Left-Click + Drag)
  ├─ Zoom with scroll wheel or middle-click
  ├─ Pan with right-click
  └─ Smooth real-time interactivity

CORE MODULES DETAIL
════════════════════════════════════════════════════════════════════════════

📄 geometry.py (Object Creation)
   ├─ CuboidFactory
   │  ├─ create_cuboid()           → Create 3D cuboid geometry
   │  └─ create_actor()            → Create colored actors
   ├─ MaterialFactory
   │  ├─ create_metallic_material()
   │  ├─ create_matte_material()
   │  └─ create_glossy_material()
   └─ GeometryHelper
      ├─ get_actor_center()
      └─ get_actor_dimensions()

📄 viewport.py (Viewport Management)
   ├─ Viewport Class
   │  ├─ __init__()               → Initialize with gradient BG
   │  ├─ _setup_lighting()         → 3-point lighting
   │  ├─ add_actor()               → Add 3D objects
   │  ├─ add_overlay_actor()       → Add 2D overlays
   │  ├─ set_camera_position()     → Camera control
   │  ├─ add_axes()                → Add coordinate axes
   │  ├─ add_title_overlay()       → Add titles
   │  └─ add_bounds_overlay()      → Add dimensions

📄 renderer.py (Rendering Engine)
   └─ RenderingEngine Class
      ├─ __init__()               → Initialize window
      ├─ add_viewport()           → Register viewports
      ├─ setup_interactor_style() → Mouse interaction
      ├─ render()                 → Display & interact
      ├─ get_render_window()
      └─ get_interactor()

📄 axes.py (Coordinate Systems)
   └─ AxisIndicator Class
      ├─ create_axes()            → 3D axes indicators
      ├─ create_cube_axes()       → Cube axes outline
      └─ create_orientation_marker()

📄 overlay.py (Text & HUD)
   ├─ TextOverlay
   │  ├─ create_text_actor()      → Generic 2D text
   │  ├─ create_corner_text()     → Positioned text
   │  └─ create_fps_monitor()     → Performance display
   ├─ ViewportBorder
   │  └─ create_border_actor()    → Border decorations
   └─ StatisticsOverlay
      └─ create_bounds_text()     → Dimension display

📄 layout.py (Viewport Arrangement)
   └─ ViewportLayout Class
      ├─ configure_cameras()      → Setup views
      ├─ add_lights()             → Add lighting
      ├─ add_axes_to_all()        → Add axes to all
      ├─ add_titles_to_all()      → Add titles
      ├─ get_viewport_configs()   → Get layout rectangles
      ├─ add_actor_to_all()       → Sync actors
      ├─ add_bounds_overlay_to_all()
      └─ enable_all_overlays()    → Enable all features

📄 config.py (Configuration)
   ├─ WINDOW_CONFIG              → Size & title
   ├─ COLOR_SCHEME               → Viewport colors
   ├─ CUBOID_CONFIG              → Default geometry
   ├─ LIGHT_CONFIG               → Lighting setup
   ├─ CAMERA_POSITIONS           → View angles
   ├─ MATERIALS                  → Material properties
   ├─ OVERLAY_CONFIG             → Text styling
   └─ INTERACTION_SETTINGS       → Feature toggles

🎨 CUSTOMIZATION
════════════════════════════════════════════════════════════════════════════

Change Geometry:
  Edit main.py line 36:
  mapper = CuboidFactory.create_cuboid(width=3.0, height=2.0, depth=1.5)

Change Color:
  Edit main.py line 37:
  color=(0.95, 0.4, 0.2)  # Orange-red

Change Material:
  Edit main.py line 40:
  material_type="metallic"  # or "matte"

Use Config File:
  Edit config.py to change:
  • Window size, title
  • Color schemes
  • Lighting intensity
  • Camera positions
  • Material properties

🔧 TECHNICAL SPECIFICATIONS
════════════════════════════════════════════════════════════════════════════

Framework:      VTK 9.5.2 (Visualization Toolkit)
Language:       Python 3.13
Environment:    Virtual Environment (venv)
Dependencies:   VTK, NumPy, Matplotlib

Window:         1600x1000 pixels (configurable)
Rendering:      Real-time 60 FPS
Viewports:      4 synchronized renderers
Lighting:       3-point professional setup
Materials:      3 types (glossy, metallic, matte)
Interactions:   Mouse-based 3D navigation

Performance:
  • Memory:     ~200 MB (with VTK)
  • CPU:        Efficient GPU-accelerated rendering
  • Scalability: Extensible for complex scenes
