LAYOUT:
  Left Half (50%)        → Main Isometric View
  Right Half (50%)       → 3 Stacked Orthographic Views
    - Top: Right View (Y-Z Plane)
    - Middle: Front View (X-Z Plane)
    - Bottom: Top View (X-Y Plane)

KEYBOARD CONTROLS - MOVE & ROTATE:

  Arrow Keys
    → Right             Move cuboid right (+X)
    → Left              Move cuboid left (-X)
    → Up                Move cuboid up (+Y)
    → Down              Move cuboid down (-Y)

  Rotation Controls (Press once per rotation)
    W                   Rotate around X axis
    S                   Rotate around X axis (opposite)
    A                   Rotate around Z axis
    D                   Rotate around Z axis (opposite)
    Q                   Rotate around Y axis
    E                   Rotate around Y axis (opposite)

  Reset
    R                   Reset to original position & rotation

MOUSE CONTROLS - CAMERA VIEW:

  Left-Click + Drag     Rotate camera around cuboid
  Scroll Wheel          Zoom in/out
  Right-Click + Drag    Pan camera

SYNCHRONIZATION:
  ✓ All 4 viewports share the same cuboid
  ✓ Moving/rotating in one view reflects in all views
  ✓ Each viewport has independent camera
  ✓ Independent mouse/keyboard interaction

EXAMPLES:

1. Rotate cuboid 90° around X axis:
   Press 'W' key

2. Move cuboid right and up:
   Press Right Arrow, then Up Arrow

3. Full rotation with reset:
   Press W, A, Q, then R to reset

4. Complex movement:
   Right → Right → Up → W → A → (mouse rotate to see from different angle)
